# Privacy

Magic Cursor does not collect keyboard input, passwords, visited URLs, documents, screen images or cursor-path telemetry. Cursor position and mouse-button events are processed in memory only for visual effects. Frontmost application bundle IDs are used locally for exclusions and are not stored as activity history or transmitted.

Local storage contains effect settings, presets, an onboarding flag, and corrupt-settings recovery backups. The macOS Keychain stores trial start/greatest observed time and license key/device receipt/validation dates. Those items are device-local, not configured for Keychain synchronization. Deleting ordinary preferences does not restart a completed trial.

When Lemon Squeezy product IDs are configured, user-requested activation, validation and deactivation send the license key and a generic device name or instance ID to `api.lemonsqueezy.com` over HTTPS POST. Existing licenses are revalidated when older than 24 hours, with retry attempts limited to at most once per hour. No computer hostname or cursor data is sent. Temporary outages preserve the receipt within its offline grace; expiry or explicit invalidation returns access to Free. Customer names/emails returned by the service are ignored. Merchant checkout opens in the user's browser and is governed by the provider's own policies.

When a real update feed/public key are configured, Sparkle sends update checks to that feed and downloads selected updates from the feed's archive host. Automatic checks and downloads are off by default and can be enabled in settings. System profiling is disabled. Network servers may receive ordinary connection metadata such as IP address and request headers; the app does not add usage analytics.

The current Gumroad beta is configured with a public product ID for license verification. Checkout opens the published Gumroad Pro product in your browser. No update feed is configured. Gumroad verification sends the license key and public product ID to `api.gumroad.com` using HTTPS POST. Successful activation increments the provider's usage counter once; revalidation does not. Customer names, emails and payment details in the reply are ignored and are not retained. Product mismatch, disabled/refunded/disputed/chargebacked purchases and flagged test purchases in production are rejected. Removing a license deletes only the local record and does not disable the seller's key or decrement a server-side device count. Gumroad integration does not claim a server-enforced device limit. Preview and smoke modes use memory-only licensing, fixture responses and no update requests. Global click observation uses only left/right button-down masks and does not block or rewrite events. Login launch uses macOS ServiceManagement.
