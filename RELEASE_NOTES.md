- Removed development notes and unnecessary explanatory text from the app.
- Raised cursor effects above application windows, including System Settings, while keeping click-through input.
- Added persistent Free, Pro and Pro trial labels in settings and the menu bar.
- Dimmed and locked unavailable Pro effects, appearance controls and presets.

- Added a direct $2.99 Pro checkout button. The same app upgrades after license verification; no separate Pro installation is needed.
- Published the free DMG on GitHub. The optional Gumroad support page remains available.

## Installation

Open the DMG, drag Magic Cursor to Applications, then launch it. Free includes Motion Ink and Kinetic Glow. Start the optional 3-day Pro trial in Settings → License.

This build is ad hoc signed and not Apple notarized. First launch may require System Settings → Privacy & Security → Open Anyway for this specific app. It targets macOS 13+ and includes arm64 and x86_64; runtime testing covers macOS 15.8.1 on Apple Silicon with one display. Protected system screens can still restrict overlays. No automatic update feed is configured.

Seller test purchase/API verification and isolated Pro activation are checked. Activation from an actual paid purchase and a real refund remain unverified. Seller test keys cannot unlock the public build; a separate local developer test app is available to the developer and is not included in this download.
